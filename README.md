## 🚀 How to Use

1. Browse prompts in the [`prompts/`](prompts/) directory
2. Copy any prompt text
3. Go to [CDance.ai](https://cdance.ai/create?model=seedance-2.0) or Seedance 2.0
4. Paste and generate your video!
