## 🚀 How to Use

1. Browse prompts by category above or search in [all.md](prompts/all.md)
2. Copy the prompt text
3. Go to [CDance.ai](https://cdance.ai/create?model=seedance-2.0) or any Seedance 2.0 endpoint
4. Paste and generate your video!
